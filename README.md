# Inkpad for iPad, iPhone and Mac

GNOME 版 Inkpad 的 Apple 平台原生版本（Swift，UIKit 画布 + SwiftUI 界面），一份代码运行在 **iPad、iPhone 和 Mac（Mac Catalyst）** 上。界面按桌面版的样式表和布局重做：同一套 Lucide 图标（直接复用桌面版的路径数据）、蓝色标题栏和工具组、浮在画布上的选项条与状态条、带品牌字样的文稿库侧栏、同样的弹出面板和对话框。各端使用**同一种 `.inkpad` 文件格式**和**同一套 Google Drive 同步协议**，所以在 Linux 上写的笔记可以在 iPad、iPhone 或 Mac 上接着写，反之亦然；两边同时改了同一本笔记时按笔画逐项合并。

## 三个平台

| 平台 | 怎么装 | 说明 |
| --- | --- | --- |
| iPad | `tools/install.sh` 或 Xcode | 主要平台：Apple Pencil（压感、悬停、双击、Pro 的捏合工具盘） |
| iPhone | `tools/install.sh <设备名或 UDID>` 或 Xcode | 窄屏布局：工具单独占一行，文稿库两列；没有手写笔，默认用手指书写、双指移动页面 |
| Mac | `tools/build_mac.sh` 生成 `dist/Inkpad.app` | 鼠标或触控板书写（无压感时按速度变化粗细）；文稿库在 `~/Documents/Inkpad`，与桌面版同一位置；Google 凭据存在 `~/Library/Application Support/Inkpad`（仅本人可读的文件） |

iPhone 和 Mac 版是后加的：主要界面（文稿库、编辑器、新建笔记本、设置）在模拟器 / 本机上看过，其余面板在窄屏上可能还有排不下的地方；Mac 上的鼠标书写、Google 登录没有实际操作验证过。

## 安装到 iPad 或 iPhone

1. 用 Xcode 打开 `Inkpad.xcodeproj`，在 *Signing & Capabilities* 里把 Team 换成你自己的（并把 Bundle Identifier 改成你自己的前缀）。
2. 连接设备，选中它，点 Run。首次需要在设备的 *设置 › 通用 › VPN 与设备管理* 里信任开发者，并打开 *设置 › 隐私与安全性 › 开发者模式*。

或者命令行一步完成（会自动找已连接的 iPad）：

```bash
tools/install.sh
```

覆盖安装会保留 iPad 上已有的笔记和设置。

## 关于"每 7 天续签一次"

免费 Apple ID 签出的 App 只有 7 天有效期，这个期限本身改不了。可选的办法：

| 办法 | 有效期 | 费用 | 说明 |
| --- | --- | --- | --- |
| **Apple Developer Program** | 1 年 | US$99/年 | 唯一真正"装一次管一年"的办法，还能用 TestFlight |
| **SideStore / AltStore** | 7 天，自动续 | 免费 | 在后台替你续签。把 `tools/build_ipa.sh` 生成的 `dist/Inkpad.ipa` 交给它即可 |
| **`tools/auto_renew.sh on`** | 7 天，自动续 | 免费 | 让这台 Mac 每 6 小时检查一次，iPad 在同一 Wi-Fi 下就重新签名安装 |
| 手动 `tools/install.sh` | 7 天 | 免费 | 到期后跑一下 |

几点事实：

- 过期只是**打不开 App**，数据不会丢：笔记仍在 App 的文档目录里（"文件"App › 我的 iPad › Inkpad），而且已经同步到了 Google Drive。重新签名安装后一切照旧。
- SideStore / AltStore 会给 App 换一个 Bundle ID，所以它和用 Xcode 装的那份是两个独立的 App。选定一种方式用下去即可（换方式也只需重新登录 Drive 同步一次）。
- `auto_renew.sh` 依赖 Xcode 的自动签名：Xcode 要保持登录 Apple ID，iPad 要在 Xcode › Window › Devices and Simulators 里勾选 *Connect via network*。Xcode 只在旧描述文件到期后才签发新的，所以到期当天可能有几个小时打不开，直到下一次检查。这个脚本没有在真机上验证过。

## Google Drive 同步

在 *设置* 里填入**与桌面版相同的**"桌面应用"类型 OAuth 客户端 ID 和密钥（或导入同一个 `google_client.json`），然后点"连接…"。权限范围是 `drive.file`，App 只能看到用同一个 OAuth 客户端创建的文件，所以必须用同一个客户端，两边才能看到同一批笔记。

同步时机：启动、回到前台（距上次超过 2 分钟）、关闭笔记本、切到后台，以及手动点同步按钮。正在编辑的笔记本在前台同步时会被跳过，切到后台时一并同步。

如果 Google 每 7 天要求重新授权一次，那是因为 Google Cloud 项目的 OAuth 同意屏幕处于"测试"状态；发布为"正式版"（个人使用无需审核）即可。

## 功能

桌面版的功能全部移植，界面、图标和文案与桌面版一致：

- 文件格式：页面、笔画（钢笔/圆珠笔/画笔/荧光笔/胶带，压感、虚线）、形状、文本框、便签、图片、PDF 背景、封面、书签、白板
- 书写：Apple Pencil 压感、预测笔迹、防手掌误触；长按吸附成规则形状；涂抹擦除；没有压感的 Apple Pencil（USB-C）自动改为按速度变化粗细；双击 Pencil 切换橡皮擦；捏一下 Apple Pencil Pro 在笔尖旁弹出弧形工具盘（工具一段可沿弧线滑动）
- 工具：套索（自由/矩形，移动、缩放、改色、旋转、置顶置底、拷贝粘贴、截图到剪贴板、存为图片）、橡皮擦（标准/整笔、筛选、自动取消选择）、形状、文本、便签、胶带、激光笔（光点/轨迹）、插入图片、尺子（手指拖动，双指旋转，沿边缘画线吸附成直线）
- 工具设置：笔面板（笔尖、压力灵敏度、稳定性、线型）、可增删改的颜色槽、可调的粗细预设
- 页面：13 种纸张模板、3 种纸色、5 种尺寸；增删、拷贝粘贴、复制、旋转、清空、更换模板、插入 PDF 页面、把图片加为一页；缩略图、大纲、书签侧栏；在笔记中查找（文本框和 PDF 文字）
- 视图：上下 / 左右翻页；白板的小地图（缩放、显示全部内容）；重新打开笔记本时回到上次的位置和缩放
- 文稿库：文件夹（颜色与图标）、收藏、废纸篓、重命名、移动、复制、搜索、排序；多选后批量导出 / 复制 / 移动 / 删除 / 恢复（接了鼠标时可拖出选框）；记住上次打开的文件夹
- 导入：PDF、Goodnotes 文档、整个文件夹（保留目录结构）、zip 存档
- 导出：矢量 PDF（可选页面范围，以及笔迹和背景 / 仅笔迹 / 仅背景）、当前页或全部页面的 PNG、Goodnotes（实验性，与桌面版相同）、`.inkpad` 文件；整个文稿库、单个文件夹或所选项目导出为 zip 存档
- 设置：外观、语言、书写选项、十字光标（Pencil 悬停时显示）、鼠标行为、翻页方向、最大放大倍数、工具栏显隐、防误触时间、输入日志；管理储存空间（恢复本机已删除的笔记、从云端还原已删除的笔记）
- 接了键盘时的快捷键：⌘Z / ⇧⌘Z / ⌘Y、⌘C / ⌘V、⌘S、⌘E、⌘F、⌘G、⌘+ / ⌘− / ⌘0、方向键和 Page Up / Down 翻页、Delete、Esc
- 界面语言：简体中文 / English / 日本語（跟随系统）

### 随桌面版 2026-10-08 更新补上的功能

- 套索：点一下选中最上面的图片、形状或文本框（不选笔画）；手指按在选区里拖动、按在边缘等比缩放；拖动时再放一根手指改为拖走副本；手指或鼠标长按弹出菜单（剪切、拷贝、复制、删除、粘贴），粘贴落在按下的位置
- 文稿库：把笔记本或文件夹拖到文件夹、路径的任意一级或返回按钮上来移动；移动可撤销 / 重做（提示条上的“撤销”、⌘Z / ⇧⌘Z / ⌘Y、长按空白处）；“移动到”改成可折叠的树且默认不预选；文件夹双击才打开
- 同步：自定义云端文件夹 ID、显示当前同步文件夹并可在浏览器打开、导出凭据 JSON（带文件夹 ID）、传输中每 10 秒写一次索引（断点续传）、每次同步核对云端实际还在的文件；同步面板里文件名固定两行、百分比单独一行
- 只以索引为准：之前 iPad 端“认领索引里没有的云端文件”的做法已随桌面版去掉

## 与桌面版的不同之处

只有 iPadOS 上做不到或没有对应物的几项：

- **全屏模式**：iPad 上的 App 本来就占满屏幕，没有窗口可切换。
- **更改文稿库位置**：App 只能使用自己的文件夹（“文件”App › 我的 iPad › Inkpad）；设置里的“打开文件夹”会跳到那里。
- **滚动条拖动、在尺子上滚动滚轮旋转、右键菜单**：这些是鼠标操作，对应的触摸操作是滚动、双指旋转和名称旁的小箭头。

## 测试

```bash
xcodebuild -project Inkpad.xcodeproj -scheme Inkpad \
  -destination 'platform=iOS Simulator,name=iPad Pro 11-inch (M5)' \
  -derivedDataPath "$TMPDIR/inkpad-dd" test
```

- `InkpadTests`：格式读写、撤销与墓碑、逐项合并、几何算法、渲染，以及用内存版 Drive 模拟两台设备的同步。
- `InkpadTests/CompatTests` + `tools/compat.py`：让**桌面版自己的 Python 代码**（`model.py`、`gdrive.sync()`）和本 App 通过同一个目录版"云盘"互相同步，验证两边格式和索引互通。
- `InkpadTests/GoodnotesTests` + `tools/goodnotes_compat.py`：Goodnotes 的读写与桌面版 `goodnotes.py` 互相对测（桌面代码写的文件和一份覆盖每种元素、每种笔画编码的合成文件由本 App 读出，结果逐点比较；本 App 导出的文件再由桌面代码读回）。
- `InkpadUITests`：用真实触摸操作 App（书写、擦除、套索、缩放、文本、PDF、白板、激光笔、尺子、查找、导出对话框、文稿库多选、小地图）。

派生数据目录不要放在工程目录里（会出现 build database 的 disk I/O error），所以上面的命令都指向了 `$TMPDIR`。

没有验证过的部分：真机上的 Apple Pencil 手感（含悬停光标、无压感笔的速度笔锋、Pencil Pro 的捏合）、接鼠标时的行为（鼠标书写 / 移动页面、文稿库选框）、键盘快捷键、真实 Goodnotes App 导出的文件，以及对真实 Google 账号的登录和同步（同步算法本身已用假云盘和桌面版代码对测过）。
